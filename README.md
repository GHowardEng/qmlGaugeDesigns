## QML Instruments Examples

Repository to explore the creation of qml components for use in instrumentation applications.

### RPM Project

`RpmGauge.qml` - Implements a re-usable and configurable tachometer component.

`main.qml` - Shows example and instantiation for a twin-engine monitor and test interface which allows the user to exercise the gauge values with the keyboard.
